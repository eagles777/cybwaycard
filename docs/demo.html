Facts about the repository

How faithful is this mirror?The check logic and regexes here are a line-for-line port of signals.py / checks.py. A parity test in the repo runs this script under Node on preset combinations and compares every check status with the Python engine. What the browser does not do: parse an AST, walk a whole repository, or write the audit log and manifest.
